💬 How to Use

  • 📝 Type any question in the chat box and press Enter
  • 🔥 Visit Trending to explore popular AI topics
  • 🔖 Save any response by hovering and clicking the bookmark icon
  • 🌐 Check Sources to see the tech stack behind this app
  • 🛠️ Visit /playground to see the Developer Playground with graph visualization

❓ Frequently Asked Questions

  • Q: Is my data stored? — No. Conversations are not saved on any server. Saved messages use your browser's local storage only.
  • Q: Which AI model is used? — GPT-OSS 120B via OpenRouter API, orchestrated through LangGraph.
  • Q: Can it search the web? — Yes! It uses Tavily Search for real-time web results.
  • Q: Is there a message limit? — No hard limit, but the free model tier may have rate limits.

🚨 Having Issues?

If the bot is not responding, check that the backend server is running. For bugs or feature requests, reach out via the About Me section.
